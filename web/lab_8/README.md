# Market — лабораторная работа № 8

Каталог из `lab_4`, перенесённый на React и Vite: шапка, поиск, панель фильтров,
карта, восемь карточек товаров и подвал. Оформление и изображения сохранены.
Фильтры по категориям, цене и наличию обновляют каталог сразу при изменении.
Если категории не выбраны, показываются товары всех категорий.
Поле поиска пока не изменяет каталог.

## Запуск

```bash
npm install
npm run dev
```

## Проверки и сборка

```bash
npm run lint
node --test tests/filterProducts.test.js
npm run build
```

Сборка создаётся в `dist/`. Для локального просмотра: `npm run preview`.
Карта загружается с Google Maps и требует подключения к интернету.
Источники фотографий указаны в `public/img/SOURCES.md`.
